# Preserved research and design history

This archive preserves the full technical research records, observations, reports, dictionaries/lookup snapshot and prior design documents used for this project, not only their curated summaries. It includes Olist/alternative assessment, TLC feasibility (including Yellow comparison), and deeper HVFHV inspection. None is a new source acquisition or a full monthly validation.

Read [START-HERE](../START-HERE.md) for authority: archived recommendations can be superseded. Markdown reports and one-off inspection worksheets are stored as `.md.txt` / `.py.txt` to distinguish history from active specifications or runnable pipeline code. Relative links and hashes inside historical text describe their original context; use the archive inventory for exported paths/current hashes. Inspection worksheets are evidence of methodology, not production modules; no automatic execution is authorized.

[Preservation ledger](archive-inventory.json) lists every included original and transformation. Only personal filesystem prefixes and a temporary download path were replaced with portable markers; technical observations remain. Career profiles, CVs and unrelated private CareerBooster records are excluded. Original research source code is preserved as inert text, not a built project.

Original large upstream datasets are not embedded; URLs, captured observations and method limits are retained. Public terms and code licensing must be reviewed separately before distribution. This ZIP is a private handoff, not permission to publish all archived content.
